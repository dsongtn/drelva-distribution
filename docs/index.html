Preview distribution · v0.1.1

Drelva Access

A small, public opt-in gateway to a privately authorized software ecosystem. Install through your existing operating-system package manager, then authenticate with the owner's server. Private applications are not distributed here.

Status: the gateway installs and verifies the public identity provider; enrollment is not live until the OAuth public client and server-side entitlement API are registered. No application or download access is granted merely by installing Drelva. Signing key below is a development-preview key.

Native Linux installation

Fedora · DNF5

First verify the signing-key fingerprint below. Register the signed repository, then install:

sudo dnf config-manager addrepo --from-repofile=https://dsongtn.github.io/drelva-distribution/drelva.repo
sudo dnf install drelva
drelva doctor

DNF verifies both the RPM signature and signed repository metadata. Confirm the preview key fingerprint when prompted.

Debian / Ubuntu · APT

Download the public key and source definition without disabling signature checks:

curl -fsSLo /tmp/drelva-preview.asc https://dsongtn.github.io/drelva-distribution/keys/drelva-preview.asc
gpg --show-keys --with-fingerprint /tmp/drelva-preview.asc
# Compare fingerprint with the independent expected value below.
sudo install -Dm644 /tmp/drelva-preview.asc /etc/apt/keyrings/drelva.asc
curl -fsSLo /tmp/drelva.sources https://dsongtn.github.io/drelva-distribution/drelva.sources
sudo install -m644 /tmp/drelva.sources /etc/apt/sources.list.d/drelva.sources
sudo apt update
sudo apt install drelva
drelva doctor

The source uses a restricted Signed-By key. Install curl and GnuPG first if your minimal OS image does not include them.

Windows and macOS

Windows

The public release contains an unattended-capable per-user Windows installer. It is currently unsigned and is therefore a development preview, not a certified Microsoft Store or WinGet community listing. WinGet manifest submission requires separate review.

Alternatively, if Scoop is installed, the public Drelva Scoop bucket provides a verified per-user installation:

scoop bucket add drelva https://github.com/dsongtn/scoop-drelva.git
scoop install drelva
drelva doctor

This Scoop installation and removal were tested on Windows 11. Scoop is not preinstalled with Windows.

macOS · Homebrew tap

brew tap dsongtn/drelva
brew install drelva
drelva doctor

Third-party Homebrew tap; Homebrew is not preinstalled on macOS. A Developer ID/notarized PKG is not yet available.
