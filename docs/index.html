Drelva

0.1.1 · utility preview

Small cross-platform command-line tool. Installation files and package sources are provided below.

Fedora

sudo dnf config-manager addrepo --from-repofile=https://dsongtn.github.io/drelva-distribution/drelva.repo
sudo dnf install drelva
drelva doctor

Debian / Ubuntu

curl -fsSLo /tmp/drelva-preview.asc https://dsongtn.github.io/drelva-distribution/keys/drelva-preview.asc
gpg --show-keys --with-fingerprint /tmp/drelva-preview.asc
sudo install -Dm644 /tmp/drelva-preview.asc /etc/apt/keyrings/drelva.asc
curl -fsSLo /tmp/drelva.sources https://dsongtn.github.io/drelva-distribution/drelva.sources
sudo install -m644 /tmp/drelva.sources /etc/apt/sources.list.d/drelva.sources
sudo apt update
sudo apt install drelva
drelva doctor

Compare the key fingerprint shown below before installing the repository key. Minimal installations may need curl, gnupg, and ca-certificates.

Windows

Installer downloads (development preview; Windows installer is not digitally signed).

With Scoop already installed:

scoop bucket add drelva https://github.com/dsongtn/scoop-drelva.git
scoop install drelva
drelva doctor

macOS

With Homebrew already installed:

brew tap dsongtn/drelva
brew install drelva
drelva doctor

The macOS PKG in the downloads is not notarized.
